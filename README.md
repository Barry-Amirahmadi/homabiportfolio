# هُما | داشبورد BI/BA هلدینگ ساختمانی فرضی

[نمایش داشبورد](https://barry-amirahmadi.github.io/homabiportfolio/) · [مطالعهٔ موردی](https://barry-amirahmadi.github.io/homabiportfolio/CASE-STUDY.html)

۸ صفحهٔ تعاملی برای تحلیل مدیریت، پروژه‌ها، نقدینگی، خرید، مشتریان، نیروی انسانی، سناریو و کیفیت داده. تمام شرکت‌ها، تراکنش‌ها و نرخ ارز فرضی‌اند. دادهٔ داشبورد در `data.js` قرار دارد و سایت بدون بک‌اند اجرا می‌شود.

منبع کامل دادهٔ مصنوعی و دیتابیس SQLite در بستهٔ محلی نمونه‌کار نگهداری می‌شود.
